
# Release notes v0.2.1

Version 0.2.1 stabilizes the public engineering surface without changing the v4.2 normative assessment semantics.

The release centralizes version identity, removes generated artifacts from source control, adds repository and version consistency checks, reorganizes documentation and tests, strengthens CI and release provenance, and adds persistent instructions for Cursor and other coding agents.

The release remains suitable for controlled local technical pilots. It does not establish production security, institutional adoption, evidence authenticity, scientific validity, regulatory authorization, clinical value, system conformance, or UNESCO endorsement.
