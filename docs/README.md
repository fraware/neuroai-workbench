
# Documentation map

- `architecture/` contains system and deployment architecture.
- `governance/` contains evidence, authority, institutional, and UNESCO-facing boundaries.
- `operations/` contains local deployment, pilot, and release procedures.
- `reference/` contains API, CLI, observatory, and browser-interface references.
- `security/` contains operational security guidance and review checklists.
- `adr/` contains durable architecture and normative-change decisions.
