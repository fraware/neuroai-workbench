# Deferred human governance overlay

Issue [#101](https://github.com/fraware/neuroai-workbench/issues/101) contains the final reviewer, owner, and release-authority layer. It is deliberately sequenced after the core programme is stable.

## Current core mode

The active development pipeline may collect approved public sources, preserve captures, compare snapshots, generate candidates, apply development-only dispositions, compile and apply non-canonical deltas, analyze reopening effects, and generate reconciled products.

The active pipeline does not create reviewer profiles, review opinions, owner approvals, or canonical release decisions.

## Boundaries retained during development

- historical and predecessor objects remain immutable;
- protected evidence remains outside public Git;
- retrieval failures remain typed operational outcomes;
- assessment mutation remains disabled;
- successors and products remain explicitly non-canonical;
- publication authority remains absent;
- substantive scientific, regulatory, clinical, conformance, institutional, and UNESCO claims remain withheld.

## Final overlay

After core completion, #101 will bind exact candidate, delta, reopening, product, and release hashes to attributable reviewer and owner decisions. Governance will be additive and will not rewrite core evidence or historical records.
