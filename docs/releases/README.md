# Release documentation

This directory separates software-release verification from development-foundation boundaries.

- [`v0.3-foundation-boundary.md`](v0.3-foundation-boundary.md) — authoritative scope, integrity, authority, external-review, canonical-publication, and institutional-deployment boundary for the v0.3 collaborative-assessment foundation.
- [`v1.0-readiness-gate.md`](v1.0-readiness-gate.md) — gate definition only. Does not authorize a `v1.0` tag, institutional readiness, or calendar commitment.
- [`v0.2.1-release-verification.md`](v0.2.1-release-verification.md) — human-readable verification record for the published v0.2.1 stabilization release. The current tag peel mismatch is a historical integrity item; it is not M0-blocking for a future `v0.3.0` tag and must not be repaired without explicit release authority.
- [`v0.2.1-release-verification.json`](v0.2.1-release-verification.json) — machine-readable v0.2.1 release-verification record.

A foundation-completion record is not a software release record. A software release record is not a canonical observatory authorization or an institutional-readiness decision.
