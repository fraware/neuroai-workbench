# NeuroAI Workbench v0.1.0 release notes

## Controlled determination

The reference workbench implementation is complete and suitable for controlled local technical pilots. Production security, institutional adoption, substantive evidence validity and system conformance remain outside software verification.

## Release scope

The release converts the v4.2 universal NeuroAI assessment instrument into a usable open-source repository with local case management, evidence custody, validation, typed decisions, migration, cross-case comparison, an offline browser interface, reproducible tests and controlled release artifacts.

## Principal technical properties

- Dependency-minimal Python package.
- Localhost-only default server.
- No remote browser assets or telemetry.
- Transparent JSON and filesystem workspaces.
- Content-addressed evidence store.
- Hash-chained events.
- Exact preservation of the three migrated pilot assessments.
- Apache-2.0 software license.

## Known limitations

- No built-in authentication, authorization or TLS.
- No encryption at rest or institutional key management.
- No malware scanning or protected-document viewer.
- No digital-signature verification.
- No multi-tenant isolation.
- No independent penetration test.
- No automated substantive evidence appraisal.
- No institutionally authorized conformance decision.
